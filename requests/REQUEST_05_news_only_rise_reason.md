# REQUEST_05: 상승이유 요약 — 네이버 뉴스 우선 근거 흐름

## 사용자 요청

- 공시보다 네이버 뉴스 수집을 우선시한다.
- 상승이유 요약은 네이버 뉴스만을 기준으로 텍스트를 구성한다.
- 주가 상승과 직접 관련된 뉴스만 수집하고, 화면 표현은 "관련 뉴스 요약"으로 톤을 낮춘다.

## 작업 범위

- evidence bundle 수집에서 OpenDART 공시 수집을 제외하고 Naver News evidence만 남긴다.
- 종목명, 주가 상승 맥락, 이유 키워드 기반의 관련성 필터를 적용한다.
- fallback 요약과 GPT 프롬프트 문구를 네이버 뉴스 기준으로 정리한다.
- 기존 UI는 evidence bundle에 포함된 뉴스 근거만 표시하도록 유지한다.
- 관련 테스트를 네이버 뉴스 전용 흐름으로 갱신한다.

## 완료 기준

- 상승이유 evidence에 `source_type=news` 항목만 포함된다.
- 관련 없는 시장 전체/ETF/단순 언급 뉴스는 제외된다.
- fallback 요약은 공시를 언급하지 않는다.
- 관련 단위 테스트가 통과한다.
